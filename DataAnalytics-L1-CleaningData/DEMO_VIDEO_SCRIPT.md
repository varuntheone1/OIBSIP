# Demo Video Script — Data Cleaning

## First 2 seconds: static title card

> Varun Shukla

> Level 1, Task 3 — Data Cleaning and Preprocessing

## Walkthrough (2–4 minutes)

1. Introduce the Titanic dataset and show the project folder.
2. Show the quality report: missing ages, missing cabins, and missing embarkation values.
3. Explain the cleaning choices: class-based median for age, mode for embarkation, and dropping Cabin because it is 77% missing.
4. Show the duplicate check, data-type corrections, and IQR outlier review.
5. Show the before-vs-after table and `titanic_cleaned.csv`.
6. Close by explaining that valid high Titanic fares were retained rather than removed automatically.
