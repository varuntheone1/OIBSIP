# LinkedIn Post Draft

Excited to share my Level 1 Task 3 project from the Oasis Infobyte Data Analytics Internship: **Data Cleaning and Preprocessing using the Titanic Dataset**.

Using Python and Pandas, I created a documented cleaning workflow that handled missing values, reviewed duplicates and outliers, standardised columns and categorical data, corrected data types, and saved an analysis-ready dataset.

Highlights:
- Imputed missing age values with passenger-class medians.
- Imputed missing embarkation values using the mode.
- Removed the 77%-missing Cabin field instead of inventing information.
- Used IQR to review outliers while retaining valid historical fares.
- Produced a reproducible before-vs-after quality report.
