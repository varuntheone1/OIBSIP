# Retail Sales Exploratory Data Analysis

Oasis Infobyte Data Analytics Internship — Level 1, Task 1.

## Objective

Explore retail transaction data to identify sales trends, customer demographics, category performance, and actionable opportunities.

## Dataset

The project uses the CC0 [Retail Sales Dataset](https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset) by Mohammad Talib. It is a synthetic dataset of 1,000 retail transactions. `retail_sales_raw.csv` is a project copy obtained from a public GitHub mirror. The original source fields are transaction ID, date, gender, age, product category, quantity, unit price, and total amount.

The mirror includes extra spreadsheet summary fields, which the notebook deliberately excludes before analysis. This is documented in the data-preparation cell.

## Analysis included

- Dataset shape, types, missing values, duplicates, and descriptive statistics
- Mean, median, mode, and standard deviation
- Monthly and quarterly revenue trends
- Revenue by age group and gender analysis
- Top 10 highest-value transaction-level purchases (the source has no product/SKU name)
- Revenue by product category
- Correlation heatmap
- Additional age-group × category heatmap
- Written observations, four actionable recommendations, and conclusion

## Run locally

```bash
pip install -r requirements.txt
jupyter notebook Retail_Sales_EDA.ipynb
```

Run all cells from top to bottom. The notebook writes the charts to `outputs/`.

## Main findings

- May is the highest-revenue month and Q4 is the highest-revenue quarter.
- Electronics is the leading revenue category.
- Customers aged 45–54 are the highest-revenue group, with ages 25–44 close behind.
- Quantity and unit price are the clearest drivers of transaction value.

## Tools

Python, Pandas, NumPy, Matplotlib, Seaborn, and Jupyter Notebook.

## Note on interpretation

Because the dataset is synthetic, this project demonstrates an end-to-end EDA method. The findings should be validated against production retail data before operational decisions are made.
